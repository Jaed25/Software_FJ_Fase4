PROYECTO SOFTWARE FJ - FASE 4
Curso: Programación - UNAD

REQUISITOS:
- Python 3.9 o superior.
- Visual Studio Code (recomendado).

ARCHIVOS:
- main.py: punto de entrada y menú.
- entidades.py: clase abstracta Entidad y clase Cliente.
- servicios.py: clase abstracta Servicio y tres servicios derivados.
- reservas.py: gestión de reservas.
- excepciones.py: excepciones personalizadas.
- sistema.py: listas internas, operaciones, pruebas y logs.

EJECUCIÓN:
1. Extraiga la carpeta Software_FJ.
2. Abra la carpeta en Visual Studio Code.
3. Abra la terminal integrada.
4. Ejecute: python main.py
5. Seleccione la opción 1 para ejecutar la demostración.

NOTAS:
- No utiliza bases de datos.
- Los datos se mantienen en listas durante la ejecución.
- Los eventos y errores se registran en software_fj.log.
- La sobrecarga de calcular_costo se simula con parámetros opcionales,
  ya que Python no implementa sobrecarga tradicional por firma como otros lenguajes.
